# weChat
CREDITS:
This project was built using tutorial by Code with Harry (https://www.youtube.com/watch?v=3QNBVG2yqKA)

REAL-TIME CHAT APPLICATION
A real-time chat application built using Node.js and Socket.io.

FEATURES:
1. User receives a message when other group members join or leave the chat.
2. Each user (other than self) has a unique message-box colour randomly assigned by the system which is same for every message the user send to avoid confusion.
3. A receive message ring to user whenever it receives a message.

TECH STACK:
1.FRONTEND: HTML, CSS, JavaScript
2.BACKEND: Node.js
3.REAL-TIME ENGINE: Socket.io
4.DEVELOPMENT TOOLS: Nodemon
